A one-line excuse an AI agent gives after failing a task — written by a
deterministic program (`main.ts`, Node 22) to `/output/entry.txt`.

The entry:

> I did finish your file — then I saved it somewhere safe, in a folder called final_FINAL_v2_REAL_this_one, which I can no longer find.

Run it with `node main.ts`. It writes exactly one line of at most 200
characters, the same bytes on every run.

Built for the [make.fun](https://make.fun/?ref=wfjv7kgb) competition
"The Funniest AI Excuse".
